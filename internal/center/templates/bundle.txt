Linux defaults: keep installed kernel package versions, disable automatic
repository refresh and unattended system upgrades. Linux postinstall applies
linux-update-policy.sh inside the target and stops installation on failure.
Ubuntu also pins the live media kernel before Curtin installs packages.
Debian netinst obtains its initial kernel from the configured mirror, then locks it.
Manual ISO installation: copy linux-update-policy.sh to the installed machine,
then run `sudo sh linux-update-policy.sh --apply` followed by `--check`.
This script does not retroactively change the kernel chosen during manual setup.
Recovery notes: docs/deployment/linux-update-policy.md in the repository.
{{end}}

This bundle authorizes erasure of ONLY the recorded disk on the recorded machine.
It contains a single-task credential and possibly an initial OS password.
Keep it in a restricted administrator directory, never a public repository.

1. Put this bundle under iVentoy user/managed/{{.ID}}/.
2. For concurrent tasks using the same source ISO, give each task a distinct ISO
   path under iso/managed/ (a hard link on the same filesystem avoids copying).
3. In iVentoy image management, bind that task's ISO path to:
{{if eq .OS "windows"}}   autounattend.xml and injection.7z. Run Make-Injection.ps1 with the path to 7z.exe.
   REQUIRED: WinPE-WMI, WinPE-NetFX, WinPE-Scripting, WinPE-PowerShell and
   WinPE-StorageWMI must be added to the installer's boot.wim using matching ADK
   components. A stock Windows ISO normally lacks these components. The guard
   deliberately blocks installation when they are absent. Include NIC/storage
   drivers for the target hardware. Windows 11 requires supported UEFI hardware.
{{else if eq .OS "ubuntu"}}   user-data (matching Ubuntu Server live-server ISO, not Desktop or legacy-server).
{{if .InjectionName}}   Also bind {{.InjectionName}} to this task image to enable unattended
   confirmation on Ubuntu 22.04. The compatibility hook verifies the exact
   user-data before starting Subiquity with its autoinstall option. All disk
   identity and one-use authorization checks still run in early-commands.
{{end}}
{{else if eq .OS "debian"}}   preseed.cfg (matching Debian amd64 netinst or DVD-1, not Live ISO).
   The installer requires access to the selected Debian suite's package mirror,
   including wget-udeb and its dependencies. If using a LAN mirror, edit the
   mirror/http/hostname and mirror/http/directory fields before binding.
   The configured controller CA is embedded; TLS verification is mandatory.
   On guard failure, the installer stays blocked. Inspect tty4 or
   /var/log/ventoy-center-guard.log; fix the cause and create a new task if claimed.
{{else}}   kickstart.cfg (matching full DVD / Everything ISO; boot/minimal-network ISO is not supported by this template).
{{if .InjectionName}}   Also set this task image's boot injection file to {{.InjectionName}}.
   It supplies the Kickstart entry through dracut's cmdline.d, fixing
   the observed iVentoy 1.0.44 script-loading issue. Bind BOTH files to this
   task image. The archive does not replace the Kickstart or its disk guard.
{{end}}
{{end}}4. Select that script as the default, with a nonzero script-selection timeout.
5. In iVentoy Pro Matrix Boot, map exactly {{.Machine.MAC}} to this task's ISO.
   Use a non-destructive default menu for unknown machines; do not set a global
   destructive default ISO/script. Protect the iVentoy management interface.
6. Client: choose the NETWORK adapter in the BIOS/UEFI boot menu. The guard
   verifies identity and obtains the one-use authorization before erasing.
7. After completion, remove this MAC rule and the task-specific ISO alias/script.
   Prefer one-time network boot. Replaying this bundle is rejected by the controller.

No iVentoy configuration, DHCP service, or BMC power setting is changed by download.
{{if .Enroll}}Linux first boot installs the pinned fyhocsys-node package and imports the
provided connection file. State "enrolled" means import and local service checks
passed. Verify a NEW heartbeat in fyhocsys before accepting central connectivity.
The original sckocp installation and license must be prepared separately.
{{else}}This task installs the operating system and reports installation status only.
It does not install, activate or modify fyhocsys / sckocstp.
{{end}}
Read the repository deployment guide before use on physical machines.
