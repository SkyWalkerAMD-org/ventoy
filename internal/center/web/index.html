镜像管理

打开 iVentoy ↗
↳

已绑定预置脚本的普通 Linux ISO，手动安装后会在新系统中放好完整配置包。进入硬盘系统后执行下面的命令，配置并检查 SSH、主机名、DHCP、内核锁定、禁用自动更新和 E610 驱动，同时安装匹配的中心软件。

sudo /root/ventoy-linux-setup.run

预置文件不会自动改动系统；执行前使用安装时创建的账户。执行后默认账户：user / ventoy、root / ventoy。保留原有用户和静态网络；不填写主机名时沿用合法的现有名称。如需驱动重启，重启后自动继续检查。

NODE SOFTWARE

软件分发

节点运行 setup，自动获取适合本机的默认软件组。

↳

服务器目录：尚未加载

直接放入 RPM / DEB 即可。节点按包格式、架构和 RPM 的 EL 大版本筛选，安装前校验包内信息与依赖。缺少依赖时从本机已配置的软件源获取；不执行全系统升级，内核保持不变。上传时先使用 .part 后缀，完成后再改为正式文件名。

节点直接执行 sudo /root/ventoy-linux-setup.run 即完成完整配置、安装默认软件并自动检查，无需 --apply。仅安装软件使用 --software；--list-software 查看候选，--check-software 检查软件结果。不会设置后台软件更新任务。

tools 根目录中的 tar.gz、tgz 和 zip 原样传到节点 /root/ventoy-tools/ 并校验，不解压执行。未变化文件跳过下载；中心替换同名文件后同步新版，节点自行改动的文件保留并报错。

需要按发行版单独指定软件时，可放入 ubuntu/22.04/amd64/default/ 等目录；有对应专属组时优先使用该组。

新版预置入口在手动和 PXE 自动安装完成后提供 /root/ventoy-linux-setup.run，无需另行下载。此前已安装的旧系统可下载下面的新版文件更新一次。

PXE INSTALL MENU

选好系统，自动安装

每个版本准备一次，客户端从网卡启动后选择对应的系统。

↳

网启选择系统 → 选择自动安装脚本 → 单内置盘自动安装。多盘在 PXE 画面选盘、输入 yes，随后自动安装并重启，无需在后台创建任务。默认锁定内核，关闭自动更新；现有 LVM / RAID 磁盘需先单独处理。各入口的选盘方式见下表。

当前菜单覆盖 CentOS、Rocky、Debian、Ubuntu Server 22.04／24.04。普通 ISO 仍用于手动安装。请将自动安装菜单用于受控装机局域网。

登记目标机器

请从目标机器核对信息；安装时会再次验证 MAC 和磁盘。

新建安装任务

先保存草稿；授权时会再次确认清空哪台机器的哪块盘。

默认锁定内核并关闭自动更新。Ubuntu 在安装阶段固定镜像内核；Debian 首次从所选安装源取得内核后锁定。

Windows 为次要支持，需要含 PowerShell 与 StorageWMI 的 WinPE。

授权安装

客户端启动后将清空目标磁盘。授权在 24 小时内有效，只允许启动一次安装。

结束失败任务

此操作只结束任务记录，不会停止客户端正在执行的安装程序。请先在客户端确认安装已停止。
