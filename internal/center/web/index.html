登记目标机器

新建安装任务

先保存草稿；授权时会再次确认清空哪台机器的哪块盘。

Windows 需要含 PowerShell 与 StorageWMI 的 WinPE。当前 fyhocsys 暂无 Windows 节点包。

授权安装

客户端启动后将清空目标磁盘。授权在 24 小时内有效，只允许启动一次安装。

结束失败任务

此操作只结束任务记录，不会停止客户端正在执行的安装程序。请先在客户端确认安装已停止。
